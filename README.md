**Estado:** PoC funcional / experimental.

### 💳 [Pipeline de Pagamentos — Confluent Cloud](https://github.com/Matheus-dotcom-bot/pipeline-pagamentos-confluent-cloud)

Pipeline de engenharia de dados com PostgreSQL, CDC/Debezium, Apache Kafka, Confluent Cloud e Flink SQL para processamento e classificação de eventos de pagamento.
